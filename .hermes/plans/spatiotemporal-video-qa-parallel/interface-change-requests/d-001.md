# Lane D interface change request 001

STATUS: BLOCKED_INTERFACE
STEP: D2

## Missing frozen interface

D2 must consume saved observations through the frozen generation and bundle APIs, but `interfaces.md` freezes only records and candidate-facing ports. It does not define callable signatures or behavior for:

- converting `tuple[ObjectObservation, ...]` into accepted relation facts/intervals, questions, and oracle answers;
- writing the resulting public/oracle bundle and returning its manifests or logical hashes;
- reporting the minimum replay-input sufficiency requirements.

The lane branch contains no `generation.py` or bundle module. The machine-local `fork/feat/stqa-dataset` ref currently exposes `generate_spatial_questions(facts)` but no bundle module, and cross-lane implementation details are not a frozen contract that replay can safely import.

## Requested contract

Please freeze and make available before D2 resumes:

1. The authoritative import paths and typed signatures for observation-to-dataset generation and bundle writing.
2. The minimum valid replay input (sample/frame count, object/relation requirements) and the exception/diagnostic contract for insufficiency.
3. The return type and definition of the root-independent logical hash(es), including whether they are manifest IDs, artifact digests, or a dedicated result record.
4. The integration ordering that ensures these APIs exist on lane D's base before replay tests and implementation are authored.

Lane D will remain blocked rather than duplicate integration-owned generation/bundle logic or guess an unstable API.
